# 🚀 Self-Growth Dashboard
> "Maybe today isn't for relationships, but about myself as an individual."

A personalized dashboard designed for self-optimization, focus, and tracking personal stats. This project was born from the realization that individual foundation must come before partnership.

## 🛠️ Tech Stack
*   **Frontend:** HTML5, CSS3 (Custom Fade-In Transitions)

## ✨ Key Features
*   **Protected Dashboard:** You can't see the goods until you're logged in. Unauthenticated users are automatically redirected to the Login page.
*   **Seamless Transitions:** Smooth CSS fade-in animations across all pages to keep the experience calm and focused.
*   **"Focus on Me" Core:** A space to track your own goals, fitness, or projects without outside noise.
